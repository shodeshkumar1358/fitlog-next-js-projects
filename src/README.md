## FitLog

FitLog is a dark-themed workout library and planning app built for people who want to organize and keep track of their workouts. Users can browse exercises, check workout details, add exercises to their daily plan, save workouts for later, and mark completed workouts.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Next.js App Router
- LocalStorage
- REST API
- React Icons

## Features

- **Workout Library** — Browse a variety of workouts with useful information such as images, categories, equipment, duration, calories, and ratings.

- **Workout Details** — Check detailed workout information including description, difficulty, equipment, sets, reps, calories, rating, and instructions.

- **Today's Plan** — Add workouts to your daily plan and easily manage them from the My Plan section.

- **Save Workouts** — Save workouts you like and access them later from the Saved section.

- **Track Workouts** — Mark workouts as completed or remove them from your plan using simple actions and toast notifications.

- **Sort & Responsive Design** — Sort workouts by duration, calories, or rating. The interface is designed to work smoothly on desktop, tablet, and mobile devices.

- **Persistent Data** — LocalStorage keeps your saved and planned workouts even after refreshing the page, so your data stays available while using the app.
